CO1 Concepts Implemented

1. Declarative UI

UI updates automatically based on JavaScript state.

2. DOM Manipulation

JavaScript updates HTML elements dynamically.

3. Virtual DOM Concept

A virtual structure is compared before updating the real DOM.

4. Unidirectional Data Flow

Data flows from application state to UI rendering.

5. Component-Driven Thinking

Header, Form, List, and Footer act like components.

6. Reactive State

UI re-renders whenever attendance data changes.
